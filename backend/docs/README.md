## 🚀 Quick Start

1. Install dependencies: `npm install`
2. Configure environment: Copy `.env.example` to `.env`
3. Setup database: `npx prisma db push`
4. Start server: `npm run dev`

## 📡 API Base URL

- Development: `http://localhost:3001/api`
